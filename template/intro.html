House rules

Everything you need is on screen.

  • You are repairing a finished page — you never build {{ challenge.site }} from scratch.
  • You never write CSS. The race is the repair: collecting a component applies it.
  • Steer with A/D, accelerate with W, brake with S. Arrow keys work too.
  • {{ challenge.minutes }} minutes is the maximum. Drive well and you will finish long before it.
  • The clock runs on the server and starts only when the race does — refreshing will not buy you more.
  • One official attempt per participant. If the clock runs out, the site stays broken.
  • Miss a component and it comes round again further up the course — but it costs you time.
  • Traffic and CSS hazards cost you speed and score, so a clean run is worth driving for.
